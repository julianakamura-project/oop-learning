# 🐍 Learning Object-Oriented Programming with Python

A collection of exercises, experiments, and small projects created while learning **Object-Oriented Programming (OOP) with Python**.

This repository documents my progress as I learn how to design programs using classes, objects, methods, inheritance, and other OOP concepts.

---

## 📚 About This Repository

The goal of this repository is to practice and understand the fundamental concepts of **Object-Oriented Programming** through practical examples.

Rather than focusing only on theory, the exercises here are designed to progressively apply OOP concepts to increasingly complex programs.

---

## 🎯 Learning Goals

Throughout this repository, I am practicing:

- Classes and Objects
- Attributes and Methods
- Constructors (`__init__`)
- Instance Variables
- Class Variables
- Instance Methods
- Class Methods
- Static Methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
- Method Overriding
- Special Methods / Magic Methods
- Modules and Packages
- Object Relationships
- Code Organization and Reusability
